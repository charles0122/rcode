# 验证记录

本机验收：2026-10-23，Rust 1.96.0，macOS arm64。

以下浏览器与视觉记录按发生时的代码版本保留，测试数量是当时的历史计数，不代表当前测试套件规模。当前协议和验证边界见末尾的 v3 记录；v3 透视数据为合成变形，不是相机实拍。

## 自动化

- `cargo fmt --check`、`node --check web/app.js`、`cargo build --release`。
- 当时的 Rust 核心共 20 个测试，其中一个测试执行 200 组固定种子的内容、角度、缩放和平移组合，两种图案均覆盖。
- 内容：空、中文/Emoji、随机二进制及各档容量边界。
- 图像：PNG、JPEG quality 85、Logo、旋转、缩放、平移，分别施加 σ=8 灰度高斯噪声、0.5% 椒盐噪声、σ=0.6px 模糊。
- 协议：固定向量，1/16/32 字节恢复，64 字节损伤拒绝，错误 CRC/版本/补零区拒绝。
- 无效输入：空白、随机噪声、QR 样式负样本、非 PNG/JPEG、超尺寸图像。QR 样式负样本不代表通用 QR 解码器兼容性测试。
- HTTP：超长内容、Unicode 非法颜色返回 400，服务随后仍可用；Host、Origin、静态路径、请求尺寸由单元测试覆盖。

## v3 四定位点单应解码（当前）

当前格式版本为 3；四个定位点使用相同的黑白黑比例。解码器从最多 12 个候选点枚举四点凸四边形，并通过四点单应变换采样数据。旧协议和历史定位比例不再接受。

自动化验证包含两种非仿射透视变形：输入图像四角映射到 `(48,82)/(694,38)/(726,687)/(78,648)` 与 `(67,44)/(704,128)/(657,718)/(95,665)`，分别覆盖 Lines 与 Dots。两种情况均恢复 payload、profile 和四个按 TL、TR、BL、BR 排列的 landmarks。当前 `cargo test --workspace --all-targets` 共 29 个测试：核心 27 个、FFI 2 个；覆盖 codec 版本、CRC、padding、相机灰度缓冲区入口和合成透视样本。
